# 🏙️ STREET CITY ONLINE

เกมเมืองออนไลน์ เล่นพร้อมกันได้สูงสุด **50 คน** ทั้งมือถือและคอม

## วิธีรัน (ต้องมี Node.js 18 ขึ้นไป — ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
node server.js
```

แล้วเปิด `http://localhost:3000` ในเบราว์เซอร์

เปลี่ยนพอร์ต: `PORT=8080 node server.js`

## ให้เพื่อนเข้ามาเล่น

| วิธี | ใช้เมื่อ |
|---|---|
| เปิด `http://IP-เครื่องคุณ:3000` | เพื่อนอยู่ในวง Wi-Fi เดียวกัน |
| `npx cloudflared tunnel --url http://localhost:3000` หรือ ngrok | ให้คนนอกบ้านเข้า โดยไม่ต้องเช่าเซิร์ฟเวอร์ (ได้ลิงก์ https) |
| อัปโหลดโฟลเดอร์นี้ขึ้น Render / Railway / Fly.io / VPS แล้วสั่ง `npm start` | เปิดเซิร์ฟเวอร์ถาวร |

เกมใช้ WebSocket พอร์ตเดียวกับหน้าเว็บ ถ้าอยู่หลัง https จะต่อ `wss://` ให้เอง

## ปุ่มควบคุม

**คอม:** W A S D เดิน/ขับ · เมาส์ เล็งทิศ · Space หรือคลิก = ต่อย · E ขึ้น/ลงรถ · F ร้านค้า/ศูนย์อาชีพ · Enter แชท

**มือถือ:** จอยซ้าย เดิน (ในรถ: ขึ้น = เร่ง, ซ้ายขวา = เลี้ยว) · 👊 ต่อย · 🚗 ขึ้น/ลงรถ · 🛒 ร้านค้า/ศูนย์อาชีพ · 💬 แชท

## กติกาในเกม

- **อาชีพ:** พนักงานออฟฟิศ (เงินเดือน), แท็กซี่ (ได้เงินตามระยะที่ขับ), ตำรวจ (เลือด 130 ลดดาเมจ จับคนมีค่าหัวได้ $200), โจร (ต่อยแล้วขโมยเงิน 12%), หมอ (รักษาคนใกล้ๆ ได้เงิน)
- เปลี่ยนอาชีพได้ที่ 💼 ศูนย์อาชีพ (ในเมือง) · ซื้อชุดปฐมพยาบาล $60 ที่ 🛒 ร้านค้า
- โดนน็อคเสียเงิน 20% แล้วเกิดใหม่ · ใครน็อคคนอื่น (ที่ไม่ใช่ตำรวจ) จะมีค่าหัว 40 วินาที
- เงินและอาชีพถูกบันทึกในไฟล์ `data.json` ผูกกับเบราว์เซอร์ของผู้เล่น (เข้าด้วยชื่อใหม่ก็ได้เงินเดิม)

## ปรับแต่ง

ค่าหลักอยู่บนสุดของ `server.js`: `MAX_PLAYERS` (ลิมิตคน), `CAREERS` (เงินเดือน/เลือด), `MEDKIT_COST`, `POLICE_BOUNTY`
