# 🏙️ STREET CITY ONLINE

เกมเมืองออนไลน์สไตล์ FiveM / GTA RP — เล่นพร้อมกันสูงสุด **50 คน** ทั้งมือถือและคอม
มุมมองบุคคลที่สาม 3D (สลับเป็นมุมมองจากด้านบนได้)

## วิธีรัน (ต้องมี Node.js 18 ขึ้นไป — ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
node server.js
```

แล้วเปิด `http://localhost:3000` · เปลี่ยนพอร์ต: `PORT=8080 node server.js`

## 🔑 รหัสแอดมิน (สำคัญ)

ช่อง "🔑 สำหรับแอดมิน" ในหน้าล็อบบี้ — ใส่รหัสถูกถึงจะได้สิทธิ์แอดมิน คนอื่นใช้คำสั่งแอดมินไม่ได้ (เซิร์ฟเวอร์ตรวจทุกคำสั่ง)

ตั้งรหัสได้ 2 ทาง:
1. **ตัวแปร `ADMIN_PASSWORD`** (แนะนำ) — เช่น `ADMIN_PASSWORD=รหัสของคุณ node server.js`
   บน Render: เมนู **Environment → Add Environment Variable** ชื่อ `ADMIN_PASSWORD` ใส่รหัส แล้ว Save (เซิร์ฟเวอร์จะรีสตาร์ทเอง)
2. ถ้าไม่ตั้ง เซิร์ฟเวอร์จะสุ่มรหัสให้ครั้งแรก แล้วพิมพ์ในหน้า Logs (บน Render: แท็บ **Logs**)

ความปลอดภัย: เก็บรหัสแบบแฮช (scrypt) · ใส่ผิด 5 ครั้งล็อก IP นั้น 10 นาที · ห้ามแชร์รหัส

**แผงแอดมิน** (ปุ่ม 🛡️ หรือกด `P`): วิ่งเร็ว · อมตะ · เงินไม่จำกัด (ซื้อฟรี กระสุนไม่หมด) · เสกเงินให้ผู้เล่น ·
วาร์ปไปหา/ดึงมาหา · เตะผู้เล่น · **ประกาศถึงทุกคน (แอดมินเท่านั้น)** · **เปลี่ยนรหัสแอดมิน**
(เมื่อเปลี่ยนรหัส แอดมินคนอื่นที่ออนไลน์อยู่จะถูกถอนสิทธิ์ทันที)

> บนโฮสต์ฟรีที่ดิสก์ไม่ถาวร รหัสที่เปลี่ยนในแผงอาจกลับไปเป็นค่าจาก `ADMIN_PASSWORD` เมื่อเซิร์ฟเวอร์รีสตาร์ท
> ถ้าเปลี่ยนรหัสแล้ว ให้ไปแก้ค่า `ADMIN_PASSWORD` ใน Environment ให้ตรงกันด้วย

## ให้เพื่อนเข้ามาเล่น

| วิธี | ใช้เมื่อ |
|---|---|
| เปิด `http://IP-เครื่องคุณ:3000` | เพื่อนอยู่ใน Wi-Fi เดียวกัน |
| `npx cloudflared tunnel --url http://localhost:3000` หรือ ngrok | ให้คนนอกบ้านเข้า (ได้ลิงก์ https) |
| อัปโฟลเดอร์ขึ้น GitHub แล้วใช้ Render / Railway / Fly.io สั่ง `npm start` | เปิดเซิร์ฟเวอร์ถาวร |

อัปเดตเกมบน Render: อัปโหลดไฟล์ `server.js` และ `index.html` ใหม่ทับใน GitHub (Add file → Upload files → Commit) Render จะ deploy ให้เอง

## ปุ่มควบคุม

**คอม:** W A S D เดิน/ขับ · เมาส์ หมุนกล้อง (คลิกในเกมเพื่อล็อกเมาส์ · Esc ปล่อย) · คลิกซ้าย = ต่อย/ยิง · Space ต่อย ·
`1-5` สลับอาวุธ · `E` ขึ้น/ลงรถ · `H` บีบแตร · `F` เข้าร้าน/ธนาคาร/ศูนย์อาชีพ · `V` สลับมุมมอง 3D/2D ·
`M` แผนที่ใหญ่ · `Tab` รายชื่อผู้เล่น · `Enter` แชท (พิมพ์ `/me ข้อความ` สำหรับแอ็กชัน RP)

**มือถือ:** จอยซ้าย เดิน/ขับ · ลากนิ้วทางขวาของจอ หมุนกล้อง · 👊 ต่อย · 🔫 ยิง · 🔄 สลับอาวุธ · 🚗 ขึ้น/ลงรถ ·
🛒 เข้าร้าน · 📷 สลับมุมมอง · 🗺️ แผนที่ · 💬 แชท · แตะ 👥 ดูรายชื่อผู้เล่น

## สิ่งที่มีในเกม

- **เมือง** 8×8 บล็อก มีทางม้าลาย เสาไฟ สวน กลางวัน/กลางคืน (รอบละ 10 นาที) เรดาร์วงกลมหมุนตามกล้อง
- **NPC:** รถจราจร 12 คัน และคนเดินถนน 28 คน (ชนคน/ทำร้ายพลเมืองได้ แต่จะได้ ★ ค่าหัว)
- **อาชีพ 5 แบบ:** พนักงานออฟฟิศ (เงินเดือน) · แท็กซี่ (ค่าโดยสารตามระยะ) · ตำรวจ (จับคนมีค่าหัว รางวัลตามจำนวนดาว) ·
  โจร (ยิงปืน ขโมยเงิน) · หมอ (รักษาคนใกล้ๆ) — เปลี่ยนที่ 💼 ศูนย์อาชีพ
- **ร้านค้า:** 🏪 ร้านสะดวกซื้อ · 🍔 ร้านอาหาร (ระบบหิว) · 🏥 โรงพยาบาล (ตายแล้วตื่นที่นี่) · 🏦 ธนาคาร (เงินในธนาคารไม่หายตอนตาย) ·
  🔫 ร้านอาวุธ (ไม้เบสบอลทุกอาชีพ · ปืนพก/SMG/ลูกซองเฉพาะโจร) · 🚗 ร้านขายรถ (4 รุ่น เลือกสีได้ รับซื้อรถเก่า 50% รถส่วนตัวล็อกเฉพาะเจ้าของ และบันทึกถาวร)
- **เสียง:** เสียงปืน แตร เครื่องยนต์ หมัด · มาตรวัดความเร็ว · บอลลูนแชทเหนือหัว · ไฮบาร์อาวุธ
- เงิน อาชีพ อาวุธ และรถ ถูกบันทึกในไฟล์ `data.json` ผูกกับเบราว์เซอร์ของผู้เล่น
