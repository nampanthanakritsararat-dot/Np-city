# 🏙️ Np-city RP

เกมเมืองออนไลน์สไตล์ FiveM / GTA RP — เล่นพร้อมกันสูงสุด **50 คน** ทั้งมือถือและคอม
มุมมองบุคคลที่สาม 3D (สลับเป็นมุมมองจากด้านบนได้) · เมืองใหญ่ 14×14 บล็อก

## วิธีรัน (ต้องมี Node.js 18 ขึ้นไป — ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
node server.js
```
แล้วเปิด `http://localhost:3000` · เปลี่ยนพอร์ต: `PORT=8080 node server.js`

## อัปเดตเกมบน Render (แบบเดิม)
1. แตกไฟล์ zip → ใน GitHub repo กด **Add file → Upload files** → เลือก `server.js` `index.html` `package.json` `README.md` → **Commit changes**
2. Render จะ deploy เอง รอสถานะ **Live** แล้วเปิดลิงก์ `.onrender.com`

เซิร์ฟเวอร์ยิงหาตัวเองทุก 8 นาทีเพื่อไม่ให้ Render ฟรีหลับ (เปิดตลอด ยกเว้นผู้สร้างสั่งรีเซ็ต)

## 🔑 รหัสแอดมิน และ 🛠️ รหัสระบบผู้สร้าง (แยกกัน)
| รหัส | ใช้ที่ไหน | ตั้งที่ Render → Environment | ถ้าไม่ตั้ง |
|---|---|---|---|
| **รหัสแอดมิน** | ช่อง "🔑 รหัสแอดมิน" หน้าล็อบบี้ → ได้ปุ่ม 🛠️/กด `P` | `ADMIN_PASSWORD` | `nampan` |
| **รหัสระบบผู้สร้าง** | แผงแอดมิน → แท็บ 🔒 ผู้สร้าง | `CREATOR_PASSWORD` | `nampan` |

- แผงแอดมิน: วิ่งเร็ว · อมตะ · เงินไม่จำกัด · เสกเงิน · วาร์ปไปหา/ดึงมาหา · วาร์ปไปสถานที่
- ระบบผู้สร้าง (ใส่รหัสก่อน): **ประกาศกลางจอ · เตะ · เสกได้ทุกอย่าง (อาวุธ รถ อาชีพ เงิน ฯลฯ) · รีเซ็ตเซิร์ฟเวอร์**
- **รีเซ็ต:** ตั้งเวลา (วินาที) → นับถอยหลังประกาศกลางจอ → ทุกคนถูกเด้งออกพร้อมข้อความ "รีเซ็ต" (เลือกล้างเซฟผู้เล่นด้วยได้ / ยกเลิกได้)
- ความปลอดภัย: เก็บรหัสแบบแฮช · ผิด 5 ครั้งล็อก IP 10 นาที · เซิร์ฟเวอร์ตรวจสิทธิ์ทุกคำสั่ง

## ปุ่มควบคุม
**คอม:** W A S D เดิน/ขับ · เมาส์หมุนกล้อง · คลิกซ้าย ต่อย/ยิง · `1-7` สลับอาวุธ · `E` ขึ้น/ลงรถ · `H` แตร · `F` เข้าร้าน/สถานที่ · `R` จับกุม (ตำรวจ) · `G` ตกปลา · `V` สลับ 3D/2D · `M` แผนที่ · `Tab` รายชื่อผู้เล่น · `Enter` แชท (`/me`, `/w ชื่อ ข้อความ` กระซิบ)

**มือถือ:** จอยซ้ายเดิน/ขับ · ลากนิ้วทางขวาหมุนกล้อง · 👊 ต่อย · 🔫 ยิง · 🔄 สลับอาวุธ · 🚗 ขึ้นรถ · 🛒 เข้าร้าน · 🚓 จับกุม · 🎣 ตกปลา · 📷 มุมมอง · 🗺️ แผนที่ · 💬 แชท
ในหน้าล็อบบี้เลือก **แนวตั้ง / แนวนอน** ได้

## สิ่งที่มีในเกม
- หน้าจอสีฟ้า "ยินดีต้อนรับสู่ Np city roleplay" ตอนเข้าเซิร์ฟเวอร์
- **สถานีตำรวจ** (เดินเข้าลานได้ กด F สมัครเป็นตำรวจ) และ **คุก** — ตำรวจกด 🚓/R จับคนที่มีค่าหัวเข้าคุก ติดคุกตามจำนวนดาว
- เดินง่าย ต่อยง่าย ยิงง่าย: ช่วยหันหาเป้า/ช่วยเล็งอัตโนมัติ ทุกอาวุธฆ่าคนได้ ดาเมจต่างกัน (มือเปล่า ไม้ มีด ปืนพก SMG ลูกซอง ไรเฟิล)
- เซฟโซน 3 จุด (ลานสีเขียว) ห้ามต่อสู้ ยืนนิ่งๆ ฟามเงินได้
- อาชีพ: ออฟฟิศ · นักเรียน · นักตกปลา · แท็กซี่ · ตำรวจ · หมอ · โจร (ความคืบหน้าของแต่ละอาชีพเซฟแยกกัน มีเลเวล)
- ร้านค้า: สะดวกซื้อ · ร้านอาหาร · โรงพยาบาล · ธนาคาร · ร้านอาวุธ (ซื้อ/ขาย) · ร้านขายรถ 3 จุด · ตลาดปลา · ร้านเสื้อผ้า (เปลี่ยนสีตัวละคร)
- ให้เงิน/ของแก่ผู้เล่นอื่น · แชท · รถน้อยลง คนเดินถนนมากขึ้น
- เงิน อาชีพ อาวุธ รถ ถูกบันทึกในไฟล์ `data.json` ผูกกับเบราว์เซอร์ของผู้เล่น (บน Render ฟรี ถ้าเซิร์ฟเวอร์รีสตาร์ทอาจหายได้)
